# SynthWave Private Beta Closeout Checklist

## Final Gate

1. `pnpm verify` passes on a clean checkout.
2. The beta artifact builds successfully.
3. The tester guide, known issues, support flow, and release notes are current.
4. No unreviewed P0 or P1 issues remain open.

## Manual Signoff

1. The [manual validation matrix](manual-validation-matrix.md) is complete.
2. Apple Silicon smoke pass completed.
3. Intel smoke pass completed.
4. Mic permission path validated.
5. BlackHole setup path validated.
6. Ollama available and unavailable paths validated.
7. Recording, screenshot, and fullscreen behavior validated.

## Closeout Artifacts

1. Final beta package.
2. Current known-issues list.
3. Release notes.
4. Post-beta backlog split into must-fix, next, and later.
