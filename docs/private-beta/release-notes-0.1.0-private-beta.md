# SynthWave 0.1.0 Private Beta Release Notes

## Included In This Beta

- Live audio capture and drag-and-drop file playback.
- Seven visualization modes and nine built-in themes.
- BPM, FPS, and AI overlay information.
- Screenshot capture and 60-second recording.
- Settings persistence, onboarding, and keyboard shortcuts.

## Setup Notes

- macOS-only private beta.
- BlackHole is recommended for system-audio capture.
- Ollama is recommended for the full AI-enabled beta experience.

## Known Limits

- Recording stops automatically after 60 seconds.
- AI labels depend on local Ollama availability.
- Performance may vary between Apple Silicon and Intel on the heaviest modes.

## Feedback We Want Most

1. Audio-device stability.
2. File playback behavior.
3. AI setup and reliability.
4. Performance on the heavier visualization modes.
5. Permission and onboarding clarity.
