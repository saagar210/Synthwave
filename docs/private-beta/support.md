# SynthWave Private Beta Support Flow

## Intake

1. Confirm whether the report came from live capture or file playback.
2. Confirm whether BlackHole or Ollama was part of the setup.
3. Collect the tester's Mac model, macOS version, and processor family.
4. Confirm whether the issue is repeatable.

## Priority

1. P0: app will not launch, crashes on startup, or loses important user output.
2. P1: a core feature is broken, but a workaround exists.
3. P2: degraded AI behavior, visual polish issues, or confusing messaging.

## Fast Workarounds

1. Restart the app after changing macOS microphone permissions.
2. Re-select the audio device after reconnecting hardware.
3. Start Ollama before launching SynthWave if AI labels are required for the session.
4. Keep recording sessions under 60 seconds when testing repeated captures.
